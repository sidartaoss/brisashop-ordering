# BrisaShop · Pedidos

Serviço de pedidos do [BrisaShop](https://github.com/sidartaoss/brisashop), loja online fictícia de uma varejista de moda. Conduz a jornada de compra do cliente na loja online: a sacola, a forma de entrega e a criação do pedido.

A documentação de arquitetura do sistema está em [brisashop-docs](https://github.com/sidartaoss/brisashop-docs).
